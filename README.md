# Tic Tac Toe
Welcome to my simple website to play a simple game of Tic Tac Toe!

It's a two-player game with bots if you want to play alone in the browser. Coded in HTML, CSS and JavaScript. There are no frameworks and nothing to install.

## Features

- Two players take turns as **X** and **O**
- The X and O marks as they're drawn
- The three squares that win the game are highlighted
- Spots a draw when the board fills up
- A **Restart** button to start a new game 
- A scoreboard of X wins, O wins and draws that is saved in the browser, so it survives a page refresh (**Reset score** clears it)
- Play against a bot: **easy** picks random squares, **hard** uses the minimax algorithm and never loses

## How to play

1. Open `index.html`.
2. X goes first. Click an empty square to place your mark.
3. Players take turns until one gets three in a row or the board is full.
4. Click **Restart** to play again.
